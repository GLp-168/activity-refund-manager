# 功能边界与后续工作

## 已实现的演示行为

- 退款服务直接创建成功记录和模拟交易号，没有调用支付机构。
- 短信服务写入发送成功记录，没有短信服务商调用。
- 评论服务评估管理员提交的星级、内容与图片，或既有评论，不抓取电商平台数据。
- 管理员为环境变量配置的单账号；JWT 保存在浏览器 localStorage。

## 使用真实业务数据前必须处理

- `PUT /api/signups/:id` 当前未校验报名者身份。需要可靠的用户身份认证和记录归属校验。
- 报名查询依赖昵称与手机号，未提供短信验证；登录与公开 API 尚无完整的限流防护。
- 管理端更新输入、评论规则结构及状态转换仍需系统性校验。
- 真实退款需要支付回调、幂等约束、失败重试及对账；当前模拟状态不能作为真实到账证明。
- 需要正式数据库迁移、备份恢复、审计策略、HTTPS 与会话安全设计。

本次仅完成公开源码准备及范围内验证，不是完整安全审计或生产验收。
